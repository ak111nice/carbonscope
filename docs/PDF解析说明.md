# 📄 PDF 解析 + 结果确认 功能说明

## 怎么用

1. 打开 `index.html` 或双击 `dist\CarbonScope.exe`
2. 点击顶部 **📄 PDF解析** 标签
3. 点"选择文件"，选一张电费单/燃气单 PDF
4. 系统自动提取出能源数据，**列成表格给你检查**：

| ✓ | 能源类型 | 数值 | 单位 | 来源 |
|:--:|---------|------|------|------|
| ☑ | 电网电力 | 1350 | MWh | PDF文本提取 |
| ☑ | 天然气 | 10.2 | 万m³ | PDF文本提取 |
| ☑ | 烟煤 | 52 | 吨 | PDF文本提取 |

5. **如果有一条是抓错的**（比如把地址栏的数字当成了用电量），**取消那个勾**就不会导入
6. 点"✅ 确认导入" → 数据进入核算引擎 → 自动算出碳排放
7. 如果全都抓错了，点"🗑 全部丢弃"重来

## 为什么这样做

- PDF 里的数字太多（金额、地址、编号、日期...），全自动抓取会有误读
- 这个确认步骤 = 人工审核一秒钟，保证数据干净
- 面试时你可以说："PDF 解析后有一道人工确认环节，防止误读账单上的非能源数字"

## 安全机制

| 防护层 | 做了什么 |
|--------|---------|
| 关键词限定 | 只抓"用电量""天然气""煤炭"这类词后面跟的数字 |
| 单位限定 | 必须有 MWh/万m³/吨 等单位才会计入 |
| 去重 | 同一种能源只保留第一次匹配到的值 |
| 人工确认 | **你现在看到的这个表格** — 最后一道防线 |
