# CarbonScope v2 部署指南

## 方式 1：GitHub Pages（免费，5 分钟）

1. 在 GitHub 新建仓库，比如 `carbonscope`
2. 把下面文件推到仓库根目录：
   - `index.html`（必须）
   - 不需要任何其他文件
3. 仓库 → Settings → Pages → Source 选 `main` → Save
4. 等 1 分钟后访问 `https://你的用户名.github.io/carbonscope`

## 方式 2：Vercel（免费，3 分钟）

1. 注册 vercel.com → New Project → 上传 `index.html`
2. 自动生成 `https://你的项目名.vercel.app`

## 方式 3：Netlify（免费，3 分钟）

1. 注册 netlify.com → Sites → 拖拽 `index.html`
2. 自动生成 `https://你的项目名.netlify.app`

## 方式 4：本地双击

直接双击 `index.html`，浏览器打开即可。
